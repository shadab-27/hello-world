# DMansion Properties - Static Replica

A simple static replica inspired by the layout/structure of dmansionproperties.com. Content and assets are original placeholders.

## Structure
- `index.html`: Home
- `about.html`: About page
- `listings.html`: Property listings with client-side filters
- `services.html`: Services overview
- `contact.html`: Contact form (client-side demo)
- `assets/css/styles.css`: Styles
- `assets/js/main.js`: Interactions

## Preview locally
From the project root:

```bash
cd /workspace/dmansion-clone-static
python3 -m http.server 8080
```

Then open `http://localhost:8080/index.html`.

## Notes
- Images are sourced from Unsplash via URLs for demo purposes.
- The contact form is client-side only and does not send real emails.
